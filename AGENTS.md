# Правила проєкту ЛР04

- Зберігати гроші цілими копійками; не приймати суму або знижку з клієнтської форми.
- Після кожного підключення SQLite вмикати FK. З’єднання закривати через teardown; контекст транзакції сам не закриває його.
- Оформлення замовлення, позиції та списання запасу виконувати однією транзакцією. Повтор того самого checkout_token не створює нове замовлення.
- Товари приховувати без фізичного видалення: їхні ID можуть залишатися в старих кошиках.
- Кожна зміна залишку або товару збільшує version; адміністративне редагування перевіряє початкову версію.
- Паролі, ключі сесії, локальні бази та браузерні сесії не включати в Git, звіт або архів.
- Підписи select і textarea задавати окремими label[for] та id. Перевіряти заповнені форми, а не лише порожні.
- Звіт писати коротко українською. Додавати тільки справжні скріншоти фактичного виконання.
